# Contribuindo para o pokemon-api

Obrigado por seu interesse em contribuir para o pokemon-api! Sua participação é muito importante para melhorar o projeto.

## Como contribuir

1. **Reportar problemas**: Use o sistema de issues para relatar bugs ou sugerir melhorias.
2. **Solicitações de pull request**: Antes de enviar um PR, assegure-se de que ele está alinhado com os objetivos do projeto.
3. **Padronização de código**: Siga as diretrizes do documento CODING_STANDARDS.md ao escrever código.
4. **Testes**: Verifique se seu código inclui testes adequados e que todos os testes automatizados passam.
5. **Revisão de código**: Todo código enviado passará por revisão antes de ser aceito.

## Comunicação

Caso tenha dúvidas, abra uma issue para que possamos discutir.

Agradecemos novamente por ajudar no desenvolvimento do pokemon-api!
